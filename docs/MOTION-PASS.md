# Ambient motion pass

The user requested motion, video or similar visual enhancement. This pass animates the existing generated artwork with CSS, preserving the larger type and inline voice interface. It adds no video download, autoplay audio, external animation library, signing request, or microphone request at page load.

Virgil, the user's OpenClaw motion-design agent, reviewed the proposed behavior from a written brief. His recommendations were scoped advice, not rendered-motion sign-off. Applied: a centered 24-second 1–1.015–1 image scale cycle; a fixed ring pulsing opacity only when the SDK reports Shria speaking; stationary text/controls; a short opacity-only day transition; hero motion paused during a voice connection/session.

The visible Pause motion / Play motion control affects decorative animation throughout the page and saves the choice locally. System reduced motion takes precedence and updates immediately when that setting changes. Before the client preference check, motion is paused. Blocked storage does not prevent use of the toggle for the current visit. Existing reduced-motion CSS disables all animation/transition. No scene movement is prescribed as a breathing exercise.

Verification covers actual animated transforms, persistent pause/reload/resume, runtime reduced-motion changes, hero pause during an SDK session, mobile layout, progress, microphone errors, and existing voice controls. The voice protocol tests use a mock provider and synthetic microphone; they do not represent a new human audio test.

Live visual inspection caught the arched image clipping the corner-mounted motion control. The control is centered within the arch; the phone regression checks all four inset corners of its actual hit area.
